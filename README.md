
# Pre-con-Dates

Pre-con-Dates is a simple Gantt Chart application designed for pre-construction planning. It allows users to visualize tasks and timelines, making project management more efficient and organized.

## Features

- Interactive Gantt Chart visualization.
- Easy task and timeline management.
- Lightweight and responsive design.
- Built with JavaScript, CSS, and HTML.

## Getting Started

Follow these steps to set up the project on your local machine and run it with a Node.js server.

### Prerequisites

Make sure you have the following installed on your system:

- [Node.js](https://nodejs.org/) (v14 or newer)
- [npm](https://www.npmjs.com/) (comes with Node.js)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Jmk125/Pre-con-Dates.git
   cd Pre-con-Dates
   ```

2. Install project dependencies:

   ```bash
   npm install
   ```

### Running the Application

1. Start a Node.js server:

   Create a simple Node server using a package like `http-server` or `express`. For simplicity, let's use `http-server`:

   ```bash
   npm install -g http-server
   ```

   Then, run the server:

   ```bash
   http-server
   ```

2. Access the application:

   Open your web browser and go to `http://localhost:8080` (or the port specified by `http-server`).

### Project Structure

- `index.html` - The main HTML file for the application.
- `styles/` - Contains all CSS files.
- `scripts/` - Contains all JavaScript files.
- `data/` - (Optional) A place for sample or mock data.
